# Data Directory

This directory contains medical datasets and knowledge base files used by CareNexus.

## Structure
- `raw/` — Raw downloaded datasets (gitignored)
- `processed/` — Cleaned and processed data ready for embedding
- `embeddings/` — Pre-computed vector embeddings

## Sources
- WHO ICD-11
- NHS Health A-Z
- MedlinePlus (NIH)
- Kaggle Symptom-Disease datasets

> ⚠️ Large data files are gitignored. See the project wiki for download instructions.
